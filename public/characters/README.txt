AUCTION 20 — Character Images Directory
=======================================
You can place original character images in this folder as PNG files named with their character ID:
e.g. bheem-1.png, shin-1.png, dora-1.png, ben-1.png, poke-1.png, etc.

Images will automatically display in the auction and squad view.
If an image is not present locally, AUCTION 20 automatically fetches the official character image from Wikipedia API, or displays a color monogram fallback.
